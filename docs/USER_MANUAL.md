# User Manual

1. Open **Mission Map**. Choose an item in **Place on map**, then click cells. A Rescue Team and one Victim must remain on passable cells.
2. Pick an algorithm and click **Find safest route**. Yellow cells animate exploration; green cells show the final route. Read cost, nodes, time, and path length in the metrics panel.
3. Use **Compare algorithms** to open the benchmark chart and metric table.
4. Open **Simulator**, configure obstacles, victims, disaster type and road condition, then generate a scenario. Return to Mission Map to route it.
5. Click **Plan multi-victim rescue** for the recommended order. Use **Replay route** or **Export PDF report** as needed.
6. Sign in with the supplied administrator account to access secure Admin statistics. Registering creates a responder account.
